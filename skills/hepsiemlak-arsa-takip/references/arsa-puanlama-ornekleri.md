# Arsa Puanlama Örnekleri — Şehir Bazlı

İlçe puanları şehre göre değişir. Bu dosya farklı şehirler için başlangıç puanı önerileri içerir.
Puanları kendi araştırmanızla güncelleyin: metro hatları, OSB'ler, kentsel dönüşüm projeleri, belediye yatırımları.

## Genel Puanlama Mantığı

| Puan Aralığı | Anlamı |
|:---:|---|
| 16-20 | Metro/raylı sistem hattı, hızlı büyüyen, yüksek talep |
| 14-16 | Gelişen konut alanları, OSB yakını |
| 10-14 | Kentsel dönüşüm, orta gelişim |
| 6-10 | Sakin, yerleşik bölgeler |
| 2-6 | Uzak, kırsal, düşük talep |
